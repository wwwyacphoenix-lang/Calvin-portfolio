FILES
- index.html: the complete responsive website (HTML, CSS and JavaScript are included in one file).

PREVIEW LOCALLY
1. Download and unzip the package.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. An internet connection is needed for Google Fonts and the sample project photos.

- Replace education placeholders with your exact institution, qualification and dates.
- Confirm the attachment organisation name, dates and duties.
- Replace illustrative stock images with your own project photos/drawings where possible.
- Add social profile links if you want them shown.
- Only publish contact details you are comfortable making public.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example calvin-portfolio.
3. Upload index.html to the repository's root folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish and open the website URL shown in Settings → Pages.

OTHER HOSTING OPTIONS
Netlify or Cloudflare Pages can also host a static site. Create a site/project and upload the folder containing index.html or connect your GitHub repository. A custom domain is optional and may cost money.

CONTACT FORM
The contact form uses a mailto link and opens the visitor's email app; it does not submit to a server. For a server-backed form, connect a form service or add a backend before relying on it for client enquiries.

IMAGES
Sample photos load from images.unsplash.com. Replace these image URLs with your own uploaded image files for a more personal and reliable portfolio.
